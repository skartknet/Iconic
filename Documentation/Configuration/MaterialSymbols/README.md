# Iconic Configuration: Material Symbols

**Backoffice template**: `<span class="material-symbols-outlined">{icon}</span>`

**CSS file**: https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@24,400,0,0

**Selector**: `(\w+)\s\w+`

**Source file**: https://raw.githubusercontent.com/google/material-design-icons/refs/heads/master/variablefont/MaterialSymbolsOutlined[FILL,GRAD,opsz,wght].codepoints


On the CSS file, you can filter out the icons you need to reduce the size of it appending &icon_names= . Check the Material docs to see how this works.
Also, there are other CSS files available depending the style of the icon you need.

There are more codepoints files in here: https://github.com/google/material-design-icons/tree/master/variablefont
Those are used to extract the available icons, but it looks like all the codepoints files in that folder have the same content.
